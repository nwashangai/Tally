# ADR 0003 — Advertising Strategy

## Status
Proposed

## Context

Tally is intended to be monetized with restrained advertising.

## Decision

Pending provider/platform spike.

## Constraints

- Critical inventory interactions remain ad-free.
- Ads must not be deceptive.
- Mobile and web may use different providers.
- Consent/privacy requirements must be handled appropriately.
- Ads must not cause significant layout shift or degrade interaction performance.
- The ad integration must be behind an application-level interface.
